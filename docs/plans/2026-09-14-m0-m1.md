# POS Native M0–M1 Execution Plan

**Goal:** Complete a reproducible engineering foundation, then deliver the
independently verifiable private canonical core.

## M0 remaining tasks

1. After explicit package-installation approval, install and lock TypeScript,
   Fastify, Drizzle, PostgreSQL driver, Zod, security plugins and test/lint
   tooling; document exact versions and licences in ADRs.
2. Add workspace package manifests, strict type checking, formatting/linting and
   `npm run verify` to run format check, lint, typecheck and all tests.
3. Validate `compose.yaml` on a host with Docker; do not install Docker without
   separate approval.
4. Configure repository-local Git identity supplied by the user, run `verify`,
   update `STATUS.md`, inspect the diff and commit M0.

## M1 tasks

1. Write failing integration tests for schema constraints and migrations.
2. Define Drizzle schemas and generated SQL migrations for user/session/token,
   page/block, asset, revision, audit and idempotency entities.
3. Implement transactional repositories and route every domain mutation through
   revision/audit/idempotency persistence.
4. Write failing tests for password hashing, secure session lifecycle, scoped
   tokens, failed-auth rate limiting and audit attribution; implement minimally.
5. Add authenticated health/version endpoints and API integration tests.
6. Implement backup manifest/restore proof tests using isolated fixtures.
7. Run full verification against PostgreSQL, update status/ADRs, review, and
   commit M1 only after evidence is green.
